# 🏛️ Arch3D - Interactive 3D Architecture Website

An interactive, modern 3D architectural visualization website designed to showcase contemporary structural concepts, spatial planning, and interior layouts in real-time 3D.

---

## 🌟 Key Features
- **3D Spatial Visualization:** Interactive 3D rendering powered by Three.js.
- **Modern Responsive UI:** Clean utility-first design styled with Tailwind CSS.
- **Interactive Controls:** Smooth camera orbit and model inspection controls.
- **Optimized Performance:** Fast asset loading and smooth frame rates across screen sizes.

---

## 🛠️ Tech Stack
- **HTML5:** Semantic document markup
- **Tailwind CSS:** Modern utility-first styling and responsive layouts
- **Three.js / WebGL:** 3D scene rendering, lighting, and camera management
- **JavaScript (ES6+):** Interactive logic and event handling
